Documentação Técnica da Avaliação

Entrega de Requisitos Funcionais, Diagrama Entidade-Relacionamento e Script de Banco de Dados.

1. Lista de Requisitos Funcionais

  • RF01 - Autenticação: Permite login seguro de almoxarifes/gerentes com tratamento de erro e redirecionamento.
  • RF02 - Painel Principal: Exibe nome do usuário, logout, indicadores de estoque e atalhos de navegação.
  • RF03 - Cadastro de Produtos: Permite inclusão, edição e exclusão de caixas de papelão e frascos plásticos.
  • RF04 - Busca Reativa: Filtra produtos por termo de pesquisa (SKU ou Nome) em tempo real.
  • RF05 - Validação de Dados: Bloqueia campos em branco, SKU duplicado ou quantidades negativas.
  • RF06 - Gestão de Estoque: Controla entradas/saídas e calcula o saldo remanescente dinamicamente.
  • RF07 - Alerta de Estoque Mínimo: Emite avisos visuais de níveis críticos em destaque na interface.
  • RF08 - Rastreabilidade: Grava data/hora, tipo de operação, quantidade e operador responsável.

2. Modelagem & Script SQL (`almoxarifado_db`)

CREATE DATABASE almoxarifado_db;
USE almoxarifado_db;

CREATE TABLE usuario (
    id_usuario INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    senha VARCHAR(255) NOT NULL,
    cargo VARCHAR(50) NOT NULL
);

CREATE TABLE produto (
    id_produto INT AUTO_INCREMENT PRIMARY KEY,
    codigo_sku VARCHAR(30) UNIQUE NOT NULL,
    nome VARCHAR(100) NOT NULL,
    categoria VARCHAR(50) NOT NULL,
    especificacoes TEXT,
    peso_kg DECIMAL(8,3) NOT NULL,
    estoque_atual INT DEFAULT 0,
    estoque_minimo INT DEFAULT 10
);

CREATE TABLE movimentacao_estoque (
    id_movimentacao INT AUTO_INCREMENT PRIMARY KEY,
    id_produto INT NOT NULL,
    id_usuario INT NOT NULL,
    tipo VARCHAR(10) CHECK (tipo IN ('ENTRADA', 'SAIDA')),
    quantidade INT NOT NULL,
    data_hora DATETIME DEFAULT CURRENT_TIMESTAMP,
    observacao VARCHAR(200),
    FOREIGN KEY (id_produto) REFERENCES produto(id_produto),
    FOREIGN KEY (id_usuario) REFERENCES usuario(id_usuario)
);
